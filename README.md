# compliance-landing-page-LOGO-
 # Compliance For Research Analysts

A pixel-perfect responsive landing page built from a Figma design using HTML and CSS. The project focuses on clean UI implementation, responsive layouts, and accurate conversion of the provided design reference.

## Features

* Pixel-perfect Figma to HTML/CSS conversion
* Fully responsive desktop and mobile layout
* Mobile sidebar navigation menu
* Clean and structured codebase
* Responsive sections and reusable styling
* Asset-based UI implementation
* Optimized spacing, typography, and alignment

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (for mobile sidebar toggle)

## Project Structure

```bash
project/
│
├── index.html
├── style.css
└── assets/
```

## Sections Included

* Responsive Navbar
* Hero Section
* Compliance Information Section
* Feature Cards
* Mobile Sidebar Navigation
